FUTUREE IT SOLUTIONS - STATIC WEBSITE

No database, login, Firebase, PHP or admin is required.

Upload all files and folders to your website root (public_html on many hosting plans, or a GitHub Pages repository). Keep assets/ and img/ folders.

Open index.html. Public pages: shop.html, explore.html, FAQ.html, Privacy.html, Terms of service.html.

The Laptops page is an enquiry catalogue, not live inventory; availability is confirmed via WhatsApp. There is no on-site customer review form because persistent public reviews require a backend or third-party service. Do not invent testimonials.

SEO: sitemap.xml and robots.txt are included. After deployment submit https://futureeitsolutions.co.za/sitemap.xml to Google Search Console.

IMPORTANT: Uploading a static site does not delete older server files. Remove obsolete admin/, api/, config.php, login pages, database files and PHP payment scripts from your live host if no longer needed. Back up your old site first.
